# Contributing

Nyxeara is a proprietary security platform. Public repositories can have different contribution rules depending on their license and purpose; read the repository-specific README first.

For security-sensitive issues, follow `SECURITY.md` rather than opening a public issue.

A useful pull request should explain the problem, include verification where appropriate, avoid unrelated refactors, contain no secrets/private infrastructure, and document security-impacting behavior clearly.

Accuracy matters more than volume.
