# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Use the security contact and disclosure process published at:

**https://nyxeara.vip/security**

Include enough technical detail to reproduce the issue safely, with affected components, impact, and relevant evidence.

## Responsible disclosure

Do not access, modify, or expose data that does not belong to you. Stop testing once the impact is established and preserve only the minimum evidence needed for responsible disclosure.
